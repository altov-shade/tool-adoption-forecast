# Tool Adoption Forecast

A fictional-data demo: will a new AI assistant reach 120 weekly active users by week four, and could stronger repeat use help?

Plain HTML, CSS and JavaScript. A fixed-seed agent simulation (first-time activation, retention, reactivation) produces the forecast, 80% prediction interval and probability. The probability depends entirely on the stated assumptions.

Run locally: open `index.html`, or `python3 -m http.server 8765`.
